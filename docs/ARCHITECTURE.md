# 独立项目的边界

本项目从「绘智公考」的 `src/exam_proto` 抽取了 HTML 试卷解析及图文节点核心。保留：

- `parser.py` 的客观题/主观题拆分、来源答案/解析对齐、材料范围判断。
- `richtext.py`、`referent_content.py` 的图文顺序、下划线和填空位。
- `question_quality.py`、`response_instructions.py` 的来源缺失和题型标记。
- `source_archive.py` 的原文快照和哈希校验。
- `material_references.py` 的材料编号解析，以及原模块中的材料引用/占位判断函数。
- `source_paragraphs.py` 的段落内容验证，移除与原项目裁决证据账本绑定的接口。

解析版本独立标记为 `huizhi-standalone-html-v1`。不导入原项目的 AI、知识图谱、正式题库、组卷、商业配置或历史运行数据；未来与原项目的解析修复需要显式同步并验证，不会自动跟随。

## 新增结构

- `scanner.py`：递归收集、组件配对、命名元数据和异常清单。
- `importer.py`：逐卷事务、原文归档、内容指纹、失败隔离和持久任务恢复。
- `database.py`：独立数据库标识、Schema、SQLite WAL、操作系统写入锁。
- `search.py`：中文 trigram 搜索、短词回退、分页和元数据筛选。
- `images.py`：显式图片缓存、格式/哈希验证、限量试跑和失败续跑。
- `web.py`：绑定 `127.0.0.1` 的只读页面，对来源文本转义，仅显示本地图片。
- `cli.py`：扫描、导入、续跑、状态、检索、导出和一致性检查。

## 身份与版本

试卷身份由来源根目录、相对子目录和文件名主体确定。同一来源中的不同版本各自保留，跨卷不强制合并题目。变化判断包含各组件内容 SHA-256、元数据和解析版本。重新导入同一目录时跳过未变化项；变化后的卷事务更新当前视图，旧解析 JSON 与归档仍保留在 `paper_revision` 和 `sources`。

一份材料只在当前卷的 `material` 表存一次，`question_material` 保存多对多引用及推断类型/置信度。来源答案称为来源声明，未经过模型或人工裁决。质量标记和推断置信度应在使用数据时一并考虑。

导入任务清单写入 `import_item`。成功卷及任务项状态在同一个事务中提交；中断后从账本继续，操作系统锁避免并发写入者重复执行同一任务。任务时间使用 UTC ISO 格式，ETA 只使用当前进程运行段的实测耗时，不把恢复前的闲置时间计算成处理耗时。

## 当前限制

- 支持现有下载器的 HTML 版式；尚未加入二进制 Word、DOCX、PDF/OCR 插件。
- 不包含 AI 修复、知识图谱、语义去重和题目裁决。
- 原文归档保证可追溯，但解析结果仍需抽样人工检查，特别是未拆分主观题、重复题号和材料引用歧义。
- 题目全文搜索不包含材料全文；一至两个字符搜索会退回子串匹配，大库上应优先使用较长关键词和筛选条件。
- 图片从源站重新获取时无法证明与下载试卷当时完全一致；记录获取后的 SHA-256 与验证结果，保留原 URL。
- 当前只验证了合成回归与十套真实试卷的小样本；不以此宣称全库识别率或完整离线率。
